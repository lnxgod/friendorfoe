Use case: ui-mockup
Asset type: visual concept for a native Android aviation observation app, Friend or Foe. This is a design reference that will be implemented using accessible native Compose controls.
Primary request: overhaul the Nearby aircraft list to feel much clearer, calmer and easier to use. Show ONE flat portrait app screen, no device bezel or presentation collage. Premium practical field instrument, no military theatrics or marketing. Use space and typographic hierarchy rather than nested cards.
Composition: Android portrait screen, dark charcoal background, near-white text, muted gray-green supporting text, one sea-green action accent. Top title "Nearby" with small supporting "Aircraft & drones". A compact tappable "Alerts · 10 mi" range control. One simple search row with a filter action. Below it an unboxed list separated by subtle hairlines; each row has a small aircraft silhouette, a bold callsign and one short type line on the left, a large distance on the right, and a small observation age. Five modest sample rows: "N407PD", "Helicopter", "2.4 mi"; "N172SP", "Cessna 172", "3.1 mi"; "UAL842", "Boeing 737", "6.8 mi"; "N128ER", "Helicopter", "18.2 mi"; "SWA216", "Boeing 737", "24.7 mi". The nearer helicopter gets a subtle priority indicator with the word "Nearby"; no red alarms for aircraft type. Leave quiet breathing room below the list.
Bottom navigation: exactly five labeled native-looking items "Nearby", "Map", "Camera", "Privacy", "More". Nearby is active, highlighted subtly in sea-green. Labels always visible. Crisp readable typography, realistic native Android screen proportions, polished functional layout. No shadows, gradients, big decorative illustrations, boxed card grid, fake charts, badges everywhere or paragraphs. This image contains illustrative sample data only.
